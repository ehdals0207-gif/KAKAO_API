# 요구사항 — Tapbit → 카카오톡 오픈채팅 체결 공유

## 목적

본인이 **거래소에서 직접 체결한 매매 내역**을 자동으로 감지해 템플릿에 실데이터를 채우고 본인이 만든 카카오톡 오픈채팅방에 전송합니다. 자동매매나 주문 실행을 개발하는 프로젝트가 아닙니다.

## 1차 범위

- 거래소: **Tapbit** 주력. Orange X / 크립파인은 범위 밖이며 향후 어댑터 확장 후보.
- 종목: BTCUSDT 무기한 선물 우선.
- 체결: 수동 주문도 감지.
- 이벤트: 신규 롱/숏 진입, 추가 진입, 부분 청산, 전량 청산, 포지션 반전.
- 메시지 전송: **선행 사용자 메시지/명령어 없이**, LOCO Headless 프로세스에서 능동 송신.
- 발송자: 본계정/별도 계정/봇 계정 중 선택 가능. 1차는 별도 테스트 계정 권장.
- 채팅방: 본인이 만든 오픈채팅방 (실제 송신 확인 완료). 팀채팅/일반 단톡방은 아직 별도 검증하지 않음.
- 카카오톡 UI 매크로·알림 답장 방식은 기본 설계에 포함하지 않음.

## 사용자 메시지 템플릿 예시

### 신규/추가 숏 진입

~~~text
#비중 3% ▼▼
> BTC / USDT
> 교차  X40
> 시장가
>'숏' 진입신호 ▼▼
※ 제 포지션공유 입니다
※ 참고하신 분들 평단 확인 차 공유해주셔도 좋습니다.
※ 판단은 각자의 기준으로 부탁드립니다
~~~

롱은 '롱', ▲▲로 자동 변경하며, 비중·배율·시장가/지정가 및 거래 데이터를 실제 이벤트 기반으로 채웁니다.

### 롱 전량 청산

~~~text
#롱 전량청산
#BTC #청산신호
롱 포지션 전량 청산 하겠습니다.

※ 참고하신 분들 수익률 체크해주시면 됩니다.
※ 포지션공유 입니다 판단은 각자의 기준으로 부탁드립니다
~~~

청산 관련 텍스트는 예시이며 실제 체결 시점에는 과거형으로 변경하는 등 오해 방지 문구를 최종 합의해야 합니다.

### 평단 후속 메시지

~~~text
#진입평단
> BTC / USDT
> 숏 평균 진입가: 100000.00 USDT
~~~

상기 수치는 테스트용 가상 값입니다. 실운영 시에는 거래소에서 확정한 **포지션 평균 진입가**를 채웁니다.

## 입력 데이터

최소 요구: 계정 식별자, 거래소, 상품/종목, 주문 ID, 체결 ID, 이벤트 시각, 체결 가격/수량/방향, 주문 유형, 포지션 방향·수량·평단, 레버리지, 교차/격리 구분, 계정 잔고 또는 비중 계산에 필요한 기준.

- 체결가와 최신 시장가와 포지션 평단은 서로 다른 지표. 메시지 필드 이름에 맞는 실제 값을 사용.
- **BUY=롱 진입, SELL=숏 진입으로 판정하면 안 됨.** 체결 전후 포지션 상태로 분류.
- 분할 체결은 주문/포지션 이벤트 단위로 모아 보고, 출력 단위를 정의.
- 비중 3%, 5%는 단순 계약 수량이 아님. '초기 증거금 / 기준 자산' 등 정확한 산식은 Tapbit 실제 필드 확인 후 확정.
- 같은 체결을 재시작·재연결 후 중복 발송하지 않아야 함.
- 실제 매매 주문 또는 출금 API는 사용하지 않음.

## 연속 발송 요구

사용자 요청은 체결 이벤트 후 템플릿 메시지가 짧은 간격으로 3건 정도 전송되고 **마지막에 진입평단**이 전송되는 동작입니다.

현재 scripts/03-burst-test.cjs는 **동일한 테스트 메시지 3건 + 가상 평단 1건**을 보내는 전송 부하 시험이며, 3건을 실제 서로 다른 체결로 분류하거나 평단을 계산하지는 않습니다.

실제 자동화에서는 사용자 요청에 맞춰 메시지 그룹/간격, 체결 집계, 평단 확정 시점, 재전송/중복 방지 정책을 별도 구현해야 합니다.
